## 关于我

AI 应用工程师，专注于大语言模型应用与面向生产环境的 AI 系统。

围绕知识检索、自然语言理解与智能体工作流开展工程实践，关注系统评估、可靠的 API 服务，以及 AI 在企业场景中的实际应用。

## 当前方向

**01 / 检索增强生成（RAG）**<br>
通过检索与重排序连接企业知识，让生成的回答有据可依。

**02 / 智能体系统**<br>
探索工具调用、记忆与规划如何协同，构建有序的智能体工作流。

**03 / 自然语言处理工程**<br>
从可靠基线出发，结合统一评估与错误分析，构建文本分类流程。

**04 / 企业级 AI 应用**<br>
将模型与实验转化为可集成、可测试、可运维的服务。
